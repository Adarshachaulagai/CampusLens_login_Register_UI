# CampusLens Authentication

A Flutter login and registration interface developed as the authentication foundation for the CampusLens mobile application.

## Features

- CampusLens branding
- Login page
- Registration page
- Email and password fields
- Show and hide password
- Password confirmation
- Form validation
- Forgot Password option
- Login and Registration navigation
- Success feedback
- Material 3 interface

## How to Run

1. Clone the repository.
2. Open the project in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Start an Android emulator or connect a device.
5. Run the application using `flutter run`.
